# Foodcost — démo

Prototype de démonstration (value test) d'un outil de pilotage du **coût matière** pour restaurants indépendants : scan de factures, mercuriale, fiches techniques et menu engineering.

Données de démo (restaurant fictif « Very French Beans »). Aucune donnée réelle, pas de backend.

## Stack
React + Vite + Tailwind v4 + Recharts.

## Lancer en local
```bash
npm install
npm run dev
```

## Build
```bash
npm run build   # -> dist/
```
